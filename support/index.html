VoxSRT support

VoxSRT creates subtitle files from saved media or an existing SRT on a Windows PC. Processing is local by default.

Before requesting help

  • Confirm the selected model is fully installed and passes its self-test.
  • Check the displayed download and temporary disk-space requirements.
  • Keep the input and output folders accessible until the job finishes.

Do not post media, audio, subtitle content, model files, API keys, credentials, personal file names, full file paths, or unredacted diagnostics.

Request support through the approved support channel. Include the VoxSRT version, Windows version, selected model names, and the step that failed. Attach a redacted diagnostic export only if you choose to do so after reviewing it.

See the VoxSRT privacy policy or report inappropriate AI output.
