VoxSRT privacy policy

Effective date: 2026-08-31. Publisher: Woofy_hoo.

Local subtitle processing

VoxSRT processes media, temporary audio, subtitle text, model responses, and generated subtitle files on your Windows device by default. It does not upload selected media, audio, file names, file paths, timestamps, credentials, diagnostics, or generated subtitles.

Model downloads

Models are downloaded only after you select an approved model in Model Manager. The request can disclose the selected model identifier and normal network metadata to the approved host, but it does not include your media or subtitle content. VoxSRT validates immutable package size and SHA-256 before activation.

  • VoxSRT Whisper large-v3 model repository on Hugging Face — operated by Hugging Face, Inc. (privacy information)
  • VoxSRT Whisper large-v3-turbo model repository on Hugging Face — operated by Hugging Face, Inc. (privacy information)
  • VoxSRT Qwen3-ASR and ForcedAligner model repository on Hugging Face — operated by Hugging Face, Inc. (privacy information)
  • VoxSRT Qwen3.5 9B model repository on Hugging Face — operated by Hugging Face, Inc. (privacy information)
  • VoxSRT Kanana 1.5 8B model repository on Hugging Face — operated by Hugging Face, Inc. (privacy information)

External translation, telemetry, and diagnostics

Optional external text translation is disabled in this release. Product telemetry and automatic diagnostic uploads are disabled. You may create a redacted diagnostic ZIP locally after reviewing its preview; VoxSRT does not send it automatically.

Store licensing and local data

Microsoft Store services provide license, trial, and purchase status. Microsoft handles account and payment data under its own terms. App settings and installed models remain in app-owned storage until removed, reset, or uninstalled. User-created SRT files remain until you delete them.

AI output

AI-generated subtitles can be inaccurate, incomplete, or inappropriate. Review them before publishing or relying on them. Use the AI output report page to report a concern.

Contact

Privacy inquiries: contact the publisher. Support: VoxSRT support.
