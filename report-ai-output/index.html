Report inappropriate AI output in VoxSRT

Speech recognition, correction, and translation models can produce inaccurate, offensive, or unsuitable text. Review subtitles before publishing or relying on them.

Submit a report through the approved reporting channel. Include the VoxSRT version, selected model names, source and target language, and a short description. Share only the minimum text excerpt needed to explain the issue and remove personal or confidential information first.

Do not send media, audio, full subtitle files, API keys, credentials, personal file names, full file paths, or unredacted diagnostics.

See the VoxSRT privacy policy and support page.
